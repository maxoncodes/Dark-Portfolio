# Maxon Portfolio Website

A modern and responsive personal portfolio website built with **HTML**, **CSS**, and **JavaScript**. It showcases my skills, work experience, services, and client testimonials in an interactive, visually appealing design.  

![Portfolio Screenshot](https://maxon.maxoncodes.com/assets/img/mod/p1.webp) <!-- Replace with your actual screenshot link -->

---

## 🚀 Features

- **Responsive Design** – Works seamlessly on desktops, tablets, and mobile devices.  
- **Sidebar Navigation** – Smooth scrolling navigation menu with toggle support.  
- **Portfolio Section** – Showcases recent works with filters and a detailed popup.  
- **Skills Section** – Interactive tabs for frontend, backend, and UI/UX skills with animated progress bars.  
- **Services Section** – Lists services with modals describing each in detail.  
- **Testimonials Section** – Swiper slider showcasing client feedback.  
- **Contact Form** – Includes email, phone, and messenger contact options.  
- **Footer Section** – Social links and quick navigation.

---

## 🛠 Technologies Used

- **HTML5**  
- **CSS3**  
- **JavaScript (ES6)**  
- **Swiper.js** – For testimonial slider  
- **MixItUp.js** – For portfolio filtering  
- **Icon Libraries** – Unicons, Boxicons
